首次使用配置步骤：
1. 前往 supabase.com 创建免费项目
2. 进入 Storage → 点击 New bucket
3. 名称填 mizu-data，勾选 Public bucket，点击创建
4. 进入 SQL Editor，执行以下策略 SQL：
-- 如果还没有创建 bucket，取消下面两行的注释：
-- INSERT INTO storage.buckets (id, name, public)
-- VALUES ('mizu-data', 'mizu-data', true);

CREATE POLICY "Allow all for mizu-data"
  ON storage.objects FOR ALL TO anon
  USING (bucket_id = 'mizu-data')
  WITH CHECK (bucket_id = 'mizu-data');
5. 回到 Settings → API，复制 Project URL 和 anon public key
6. 粘贴到上方配置栏，点击 保存配置
点击上方 SQL 可一键复制 · 使用 Storage 模式，无数据大小限制
